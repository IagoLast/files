# Agent Skills

Reusable skills for frontend development:

- `frontend-architecture`: design and review predictable React architectures with explicit dependency and state boundaries.
- `frontend-testing`: write behavior-focused Vite SPA tests in a real browser with Vitest Browser Mode.

Install them with:

```bash
npx skills add IagoLast/files
```

The CLI lets you choose one or both skills and the agents where they should be installed.
